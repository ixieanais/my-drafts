# MyDrafts

A note-taking app that lets you manage notes

## About

MyDrafts is a note-taking app that lets you manage notes. Built on Vue & Electron.

> The template was taken from this [repository](https://github.com/Deluze/electron-vue-template).

## Getting started

### Installation

```bash
git clone https://github.com/ixieanais/my-drafts.git
cd my-drafts

bun install
```

### Developing

```bash
bun dev
```

### Building

```bash
bun run build

# or

bun run build:win  # uses windows as build target
bun run build:mac # uses mac as build target
bun run build:linux # uses linux as build target
```
